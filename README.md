# Student Study & Task Management System

## Overview

The Student Study & Task Management System is a Python-based project designed to help students manage their tasks and analyze their academic performance.

The project provides a simple menu-driven system where users can add, view, search, delete and sort tasks. It also allows users to enter marks, calculate average marks, find the highest and lowest marks, and identify a performance category.

The project demonstrates problem-solving and programming concepts covered in CSE1021 Introduction to Problem Solving and Programming.

## Features

### 1. Task Manager
- Add new tasks
- View all tasks
- Delete tasks
- Manage tasks through a menu-driven interface

### 2. Performance Analyzer
- Enter marks for multiple subjects
- View entered marks
- Calculate average marks
- Find highest marks
- Find lowest marks
- Display performance category

### 3. Search & Sort
- Search for a particular task
- Sort tasks
- Sort marks
- Display organized results

### 4. Main Menu
- Provides access to all major modules
- Allows the user to navigate between modules
- Provides an option to exit the system

## How to Run
-Install Python on the system.
-Open Python IDLE.
-Keep all project files in the same folder.
-Open main.py in IDLE.
-Select Run → Run Module or press F5.
-The main menu will appear in the Python Shell.
-Select the required option by entering the corresponding number.

## Testing

-The project can be tested by checking each module separately.

Task Manager Testing
-Add a task and verify that it appears in the task list.
-View tasks when no tasks are present.
-Delete a valid task.
-Enter an invalid task number and verify the error message.
Performance Analyzer Testing
-Enter marks for multiple subjects.
-Check the calculated average.
-Check the highest and lowest marks.
-Verify the performance category.
Search & Sort Testing
-Search for an existing task.
-Search for a task that does not exist.
-Sort tasks.
-Sort marks.
