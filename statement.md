# Project Statement

## Project Title

Student Study & Task Management System

## Problem Statement

Students often need to manage multiple tasks while also keeping track of their academic performance. Managing these activities separately can make it difficult to organize tasks and review performance efficiently.

The Student Study & Task Management System provides a simple Python-based solution for managing student tasks and analyzing academic marks in one system.

## Scope of the Project

The project focuses on providing basic task management and academic performance analysis features.

The system allows users to:

- Add and view tasks
- Delete tasks
- Search for tasks
- Sort tasks
- Enter subject marks
- View marks
- Calculate average marks
- Find highest and lowest marks
- Display a performance category

The project is developed as a menu-driven Python application.

## Target Users

The primary target users are:

- School students
- College students
- Students who want to organize their tasks
- Students who want to perform basic analysis of their marks

## High-Level Features

### Task Management
The user can add, view and delete tasks.

### Performance Analysis
The user can enter marks and calculate average, highest and lowest marks.

### Search and Sorting
The system provides task searching and sorting of tasks and marks.

### Menu-Based Navigation
The main menu allows the user to access different modules of the system.

## Project Objectives

- To apply problem-solving techniques using Python.
- To implement functions and modular programming.
- To use lists for storing tasks and marks.
- To apply conditional statements and loops.
- To implement searching and sorting operations.
- To develop a practical application based on concepts learned in CSE1021.

## Expected Outcome

The expected outcome is a functional Python application that allows students to manage their tasks and perform basic analysis of their academic marks through a simple menu-driven interface.
